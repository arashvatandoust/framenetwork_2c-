# .NET Framework – Part 2 Assignments

This repository contains a set of **C# projects** developed as part of a training module on the **.NET Framework**.  
Each subfolder represents an individual assignment designed to enhance programming fundamentals, object-oriented design, and structured problem-solving.

---

## Project Overview

- `asp/` – A starter **ASP.NET MVC** project that introduces basic routing, controllers, and model-view communication.  
- `final/` – The concluding project combining core OOP concepts, exception handling, and data processing.  
- `method/` – Exercises built around **method construction**, parameter passing, return values, and overloading.  
- `operators/` – Code examples exploring how arithmetic, logical, and comparison operators behave in different cases.  
- `polymorphism/` – Practical implementations of **inheritance**, abstract classes, and interfaces for flexible design patterns.  
- `portfolyo/` – A final compilation project uniting all previous exercises into a cohesive showcase.

> The project directory mirrors the repository’s internal organization.
